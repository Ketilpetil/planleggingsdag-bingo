# 🎯 Planleggingsdag-bingo

En humoristisk bingo-app for planleggingsdagen – kjører rett i nettleseren, ingen installasjon nødvendig.

## Slik bruker du den
1. Last ned `planleggingsdag-bingo.html` (eller åpne den direkte via Raw-lenken under).
2. Dobbeltklikk på fila – ferdig!
3. Klikk av det som skjer underveis. Få en hel rad, kolonne eller diagonal = **BINGO** 🎉

Hver gang noen åpner appen blandes 25 kategorier tilfeldig ut av en pool på 32, så alle får sitt eget brett.

### Raw-lenke (åpne uten nedlasting)
`https://raw.githubusercontent.com/Ketilpetil/planleggingsdag-bingo/main/planleggingsdag-bingo.html`

## For kolleger på samme nettverk
```bash
python3 -m http.server 8931
# åpne http://localhost:8931/planleggingsdag-bingo.html
```
